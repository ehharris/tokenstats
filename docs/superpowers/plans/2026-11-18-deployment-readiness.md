# Deployment Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `tokenstat.py` runnable from anywhere on a fresh machine — all of its own state in `~/.tokenstat/`, a `--help` that shows only what a user needs, and the duplicated code in the query/ingest/dispatch layers collapsed — with zero change to displayed output.

**Architecture:** One stdlib-only script (`tokenstat.py`) with a path-resolution layer (pure functions + module globals), a one-time state migration that runs only when the store default is in use, and three dedup passes that keep every public function name and row-dict shape intact. Tests are one file (`test_tokenstat.py`) that calls both the library functions and `main()` in-process, plus a golden byte-identity harness.

**Tech Stack:** Python 3 (stdlib only: `argparse`, `sqlite3`, `json`, `os`, `re`, `datetime`, `colorsys`, `collections`), `unittest`, SQLite.

**Spec:** `docs/superpowers/specs/2026-11-18-deployment-readiness-design.md`

## Global Constraints

- Stdlib only; no install step; the tool stays one file.
- `python3 -m unittest test_tokenstat` passes (393 tests today, more after this plan), and `python3 -W error::ResourceWarning -m unittest test_tokenstat` passes with no warnings.
- `golden/` stays byte-identical: run the suite **without** `TOKENSTAT_UPDATE_GOLDEN`. If a golden diff appears, the change is wrong — do not re-pin.
- `--json` output is generated by a comprehension over `r.items()`, so **row-dict key insertion order is pinned output**. Any rebuilt row dict must produce the same keys in the same order.
- Importing `tokenstat` must not touch the filesystem: no `mkdir`, no migration, no file moves at import. Path helpers are pure string arithmetic.
- `THEMES_DIR` and `THEME_CONFIG` stay module-level globals read at call time (the suite patches them with `unittest.mock.patch.object`).
- Every public function name and signature that `test_tokenstat.py` imports stays intact: `record`, `import_unsloth`, `import_unsloth_runs`, `import_opencode_steps`, `query_sessions`, `query_events`, `query_runs`, `daily_*`, `total_*`, `reconcile`, `main`, plus the display primitives.
- The six options `--min-in`, `--min-out`, `--db`, `--src`, `--unsloth-db`, `--from-unsloth` stay fully functional — the suite passes them on ~230 call sites and the cron line relies on `--db`-style overrides never being needed but must keep working.
- Hidden from `-h` only via `help=argparse.SUPPRESS`; no behavior change.
- Date windows stay local-time and until-day inclusive via `_day_end_ms` (invariant 4); sources stay read-only `file:...?mode=ro` (invariant 5); no double counting (invariant 1).
- Work on a branch off `master`; commit per task. Repo has no remote — no push.

## Review Focus

- **A fresh machine with no `~/.tokenstat` and no source databases.** Expect: the directory is created, each missing source prints its existing `warning: could not read ...` line, the report renders from the empty store, exit 0 — never a traceback.
- **A legacy store that cannot be moved** (read-only script dir, cross-device). Expect: a warning naming both paths and the legacy file used as the store for that run — never a silently empty report that looks like lost history.
- **A hidden flag still in someone's history or cron.** Expect: `--min-in 10000`, `--from-unsloth`, `--db`, `--src`, `--unsloth-db` parse and behave exactly as before despite being absent from `-h`.
- **The aggregate/ingest refactor moving a byte.** Expect: identical tables and identical `--json` key order; the row-shape pin added in Task 5 is the early warning for key-order drift.
- **`XDG_DATA_HOME` set to something useless** (empty, relative). Expect: the `~/.local/share/opencode/opencode.db` fallback, not a relative path resolved against the cwd.

class MigrationTests(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.TemporaryDirectory()
        self.addCleanup(self.tmp.cleanup)
        self.state = os.path.join(self.tmp.name, "state")
        self.legacy = os.path.join(self.tmp.name, "legacy")
        os.makedirs(self.legacy)

    def test_creates_the_state_dir_and_uses_it_when_empty(self):
        self.assertEqual(tokenstat.default_store(self.state, self.legacy),
                         os.path.join(self.state, "usage.db"))
        self.assertTrue(os.path.isdir(self.state))

    def test_a_legacy_store_moves_into_the_state_dir(self):
        old = os.path.join(self.legacy, "usage.db")
        with open(old, "w") as fh:
            fh.write("history")
        code, out, err = "", "", ""   # capture stderr via redirect_stderr
        with contextlib.redirect_stderr(io.StringIO()) as err:
            used = tokenstat.default_store(self.state, self.legacy)
        self.assertEqual(used, os.path.join(self.state, "usage.db"))
        self.assertEqual(open(used).read(), "history")
        self.assertFalse(os.path.exists(old))
        self.assertIn("migrated", err.getvalue())

    def test_wal_and_shm_siblings_move_too(self):
        for suffix in ("", "-wal", "-shm"):
            with open(os.path.join(self.legacy, "usage.db" + suffix), "w") as fh:
                fh.write(suffix)
        tokenstat.default_store(self.state, self.legacy)
        for suffix in ("", "-wal", "-shm"):
            self.assertFalse(os.path.exists(
                os.path.join(self.legacy, "usage.db" + suffix)))

    def test_migration_is_a_no_op_once_the_store_exists(self):
        os.makedirs(self.state)
        keep = os.path.join(self.state, "usage.db")
        with open(keep, "w") as fh:
            fh.write("new")
        with open(os.path.join(self.legacy, "usage.db"), "w") as fh:
            fh.write("old")
        tokenstat.default_store(self.state, self.legacy)
        self.assertEqual(open(keep).read(), "new")

    def test_an_unmovable_legacy_store_is_used_in_place(self):
        old = os.path.join(self.legacy, "usage.db")
        with open(old, "w") as fh:
            fh.write("history")
        with unittest.mock.patch.object(tokenstat.os, "replace",
                                        side_effect=OSError("cross-device")):
            with contextlib.redirect_stderr(io.StringIO()) as err:
                used = tokenstat.default_store(self.state, self.legacy)
        self.assertEqual(used, old)                      # never an empty store
        self.assertIn("could not migrate", err.getvalue())

    def test_legacy_theme_files_move_with_the_store(self):
        old_themes = os.path.join(self.legacy, "themes")
        os.makedirs(os.path.join(old_themes, "examples"))
        with open(os.path.join(old_themes, "mine.json"), "w") as fh:
            fh.write("{}")
        with open(os.path.join(old_themes, "README.md"), "w") as fh:
            fh.write("docs")
        with open(os.path.join(old_themes, "examples", "gta.json"), "w") as fh:
            fh.write("{}")
        with contextlib.redirect_stderr(io.StringIO()):
            tokenstat.default_store(self.state, self.legacy)
        self.assertTrue(os.path.exists(
            os.path.join(self.state, "themes", "mine.json")))
        self.assertTrue(os.path.exists(os.path.join(old_themes, "README.md")))
        self.assertTrue(os.path.exists(

- [ ] **Step 3: Implement `default_store(state=None, legacy=None)`**

Place it after the Task 1 helpers. Default the arguments from the module globals **at call time** (`state = STATE_DIR if state is None else state`) so a patched global steers it, mirroring the existing `THEMES_DIR` comment in `main()`. Behavior, in order:

1. `os.makedirs(state, exist_ok=True)`; on `OSError`, warn `warning: could not create <state>: <exc>; using <legacy>/usage.db instead` to stderr and return `os.path.join(legacy, "usage.db")`.
2. Store move: if `<legacy>/usage.db` exists and `<state>/usage.db` does not, `os.replace` the `-wal`/`-shm` siblings first (skip absent ones) and `usage.db` **last**, then print one stderr line `migrated store: <old> -> <new>`.    *Amended during execution (Task 2 review, ruling in the SDD ledger): the step as originally written moved the main file first and fell back to `<legacy>/usage.db` on any `OSError`, which hands `main()` a path with nothing at it when a sibling fails after the main file crossed over — `sqlite3.connect` seeds an empty store there, the real history sits unseen at the other path, and the next run never retries. The design doc's "keeps using the legacy file rather than showing an empty report" is the binding intent.*
3. Themes move: if `<legacy>/themes` is a directory and `<state>/themes` is not, create the latter and `os.replace` each top-level `*.json` in it (never `README.md`, never the `examples/` subfolder), printing one `migrated theme file: ...` line each. 4. Return `<state>/usage.db` unless step 2 failed.

- [ ] **Step 3: Implement `_grouped_aggregates`**
